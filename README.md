# 报价单管理系统

这是一个为玻璃深加工企业设计的报价单管理系统，基于PHP开发，使用MySQL或SQLite作为数据库。

## 功能特性

- 客户管理：维护客户信息，包括速记码、简称、全称、地址、电话等
- 产品管理：管理产品信息，包括名称、原料厂家、单价、计价单位、产品类型
- 报价单管理：创建和管理报价单，支持版本控制和生效状态管理
- 报价单项目管理：为报价单添加具体的产品项目
- 报价单对比：对比多个报价单的价格差异
- 用户管理：简单的用户权限管理，区分销售主管和客服角色
- 权限控制：销售主管拥有编辑权限，客服仅可查看

## 系统要求

- PHP 8.0 或更高版本
- MySQL 5.5 或更高版本，或 SQLite 3
- PDO 扩展必须启用
- Web服务器（如Apache或Nginx）

## 安装步骤

1. 克隆或下载项目代码到Web服务器目录

2. 安装依赖（如果使用Composer）：
   ```bash
   composer install
   ```

3. 配置数据库：
   - 编辑 `config/database.php` 文件，配置数据库连接参数
   - 支持MySQL和SQLite两种数据库

4. 运行安装脚本：
   ```bash
   php install.php
   ```
   该脚本会：
   - 创建数据库（如果使用MySQL）
   - 运行所有数据库迁移
   - 创建默认管理员用户（用户名：admin，密码：admin123）

5. 配置Web服务器：
   - 将网站根目录指向 `public` 文件夹
   - 确保 `.htaccess` 文件（如果使用Apache）或相应的重写规则已配置

## 使用说明

1. 访问系统首页，使用默认管理员账户登录：
   - 用户名：admin
   - 密码：admin123

2. 登录后建议立即修改密码

3. 系统主要功能模块：
   - 客户管理：添加和维护客户信息
   - 产品管理：添加和维护产品信息
   - 报价单管理：创建报价单并添加产品项目
   - 报价单对比：选择多个报价单进行价格对比
   - 用户管理：添加和管理其他用户（仅销售主管可见）

## 目录结构

```
├── app/                 # 应用核心代码
│   ├── Controllers/     # 控制器
│   ├── Models/         # 数据模型
│   └── Database/       # 数据库相关
├── config/             # 配置文件
├── database/           # 数据库迁移文件
│   └── migrations/     # 数据库迁移脚本
├── public/             # Web入口目录
├── resources/          # 视图模板
│   └── views/          # 视图文件
└── vendor/             # Composer依赖（如果使用）
```

## 技术栈

- 后端：PHP 8.0+
- 前端：Tailwind CSS, jQuery
- 数据库：MySQL 或 SQLite
- 其他：PDO扩展

## 安全说明

- 系统使用密码哈希存储用户密码
- 实现了基本的会话管理
- 对销售主管和客服角色进行了权限分离
- 对用户输入进行了基本的HTML转义处理

## 注意事项

- 请在生产环境中修改默认的管理员密码
- 建议配置HTTPS以提高安全性
- 定期备份数据库
- 根据实际需求调整权限控制逻辑

## 开发说明

- 控制器位于 `app/Controllers/` 目录
- 模型位于 `app/Models/` 目录
- 视图文件位于 `resources/views/` 目录
- 数据库迁移文件位于 `database/migrations/` 目录
- 路由定义在 `public/index.php` 文件中
